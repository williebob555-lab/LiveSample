# LiveSample brand kit

_Source of truth: the `.svg` files in this folder. Everything in `png/` and
`build/icon.*` is generated by `npm run brand` — never hand-edit them._

LiveSample is a sibling of [LivePatch](https://github.com/williebob555-lab/livepatch).
The two marks are built from the same parts, on purpose: the same dark tile, the
same rounded stroke drawing the **L**, a second form in audio blue that finishes
the name, and a wordmark where "Live" is shared and exactly one letter is
swapped for an object.

| | LivePatch | LiveSample |
| --- | --- | --- |
| The L | CV cable, purple | Recording stroke, tape amber |
| Second form | Audio socket = the P's bowl | One waveform cycle on its side = the S |
| Story | The letterform is the patch | The live take becomes the sample |
| Wordmark *i* | A fader | A recording-level meter with a record light |
| Coloured half | "Patch" in audio blue | "Sample" in audio blue |

## The mark

One continuous stroke: the amber L's foot runs straight into the bottom of a
blue S. The S is a sine cycle turned on end, so it reads both as a letter and as
a waveform. Where the colours meet, the amber end sits over the blue like a
plug in a jack — LivePatch's cable-into-socket, restated.

## Files

| File | Use it for |
| --- | --- |
| `mark-square.svg` | The mark. App icon ≥ 64 px, anywhere square. |
| `mark-square-small.svg` | 32–48 px only. Thicker stroke, S opened up. |
| `mark-square-tiny.svg` | 16–24 px only. Heavier still, fills the tile. |
| `mark-circle.svg` | Avatars and anything masked to a circle. |
| `mark-mono.svg` | One colour, inherits `currentColor`, no tile. |
| `wordmark.svg` / `wordmark-light.svg` | Name alone, dark / light backgrounds. |
| `lockup-horizontal.svg` / `-light.svg` | **Primary lockup.** Mark + name. |
| `banner-readme.svg` | 1280×280 README header. |
| `banner-social.svg` | 1280×640 GitHub social preview. |

`npm run brand` maps the icon sizes: 256/128/64 from `mark-square`, 48/32 from
`-small`, 24/16 from `-tiny`. When changing the mark, check the magnified
`.ico` entries, not the SVG zoomed out.

## Colour

Shared with LivePatch's signal palette, so the family reads as one:

| Role | Hex | Where |
| --- | --- | --- |
| Tape amber | `#e8a13d` | The L, the meter-*i*. Also the app's single UI accent (`--accent`). |
| Audio blue | `#5fb2ff` | The S, "Sample". Brand only — never colours a control in the app. |
| Field | `#14161a` | The tile. |
| Raised field | `#1b1f26` | The tile when it sits on `#14161a` or the app background. |
| Meter track | `#333c49` | The meter-*i*'s empty part. |
| Text | `#e8ecf2` | "Live". |
| Muted | `#94a3b8` | Taglines. |

Light backgrounds: text `#14161a`, amber `#b8721c`, blue `#1f6fd0`, track
`#d5dae2`. The dark-field colours do not hold contrast on white.

## Type

**Inter** (bundled in the app via `@fontsource/inter`). Bold 700 at −4 tracking
for the name, medium 500 for taglines. The wordmark is typeset, so use the PNGs
where exact shape matters.

Below about 24 px the meter-*i* stops reading — set the name as plain text
there (the app's top bar does: "Live" in text colour, "Sample" in blue, bold).

## Rules

- **One substitution only.** The meter-*i*. Don't also turn the *S* of "Sample"
  into a waveform — the mark already does that.
- **Don't recolour the stroke halves.** Amber is the recording, blue the audio.
- **Don't re-space** the mark and wordmark — use the lockups.
- **On dark backgrounds** put the mark on the raised tile (`#1b1f26`), as the banners do.
- **Clear space** is the mark's corner radius (56 units at mark scale), already
  inside the lockup viewBoxes.
